# javascript-lotto-precourse

## 로또

## 프로젝트 개요

- 여러분도 로또 당첨의 주인공이 되실 수 있습니다.
- 원하는 금액을 입력해 원하는 만큼 로또를 구매해 보세요.
- 당첨 번호와 보너스 번호도 여기서는 여러분의 마음입니다!
- 구매한 로또의 번호와 당첨 번호를 비교해 보며 본인의 운을 확인해 보세요!
- 수익률도 확인해 보실 수 있습니다!!

## 시스템 사용 설명서

### 실행 방법

1. **프로젝트를 fork 한다.**

2. **프로젝트를 clone 한다.**

```bash
git clone https://github.com/whitecity01/javascript-lotto-8.git
```

3. **아래의 명령어를 입력한다.(node.js 버전은 22.19.0 버전 이상)**

```bash
npm install
npm run start
```

### 입력

1. **로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.**

   ```bash
   14000
   ```

2. **당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.**

   ```bash
   1, 2, 3, 4, 5, 6
   ```

3. **보너스 번호를 입력 받는다.**
   ```bash
   7
   ```

## 기능 목록

### 1. 로또 정보를 관리하는 기능

- 로또 번호 저장
- 로또 번호 검증
  - 로또 번호는 숫자 1~45
  - 로또 번호는 중복없는 6개의 숫자

### 2. 로또 시스템 입력 기능

- 구입 금액 입력
- 당첨 번호 입력
- 보너스 번호 입력

### 3. 로또 시스템 입력 검증 기능

- 구입 금액 검증
  - 1000원 단위의 숫자
- 당첨 번호 입력
  - 쉼표를 구분으로 숫자를 입력
  - 당첨 번호는 숫자 1~45
  - 당첨 번호는 중복없는 6개의 숫자
- 보너스 번호 입력
  - 당첨번호와 중복되지 않는 숫자 1~45
- 검증 실패 시 에러 메세지 출력 후 재입력

### 4. 로또 구매 기능

- 구입 금액을 통해 로또 구입
- 중복되지 않는 랜덤한 숫자 6개를 가진 로또 생성

### 5. 로또 당첨 결과 조회

- 구매한 로또의 당첨 결과 계산
- 구매한 로또들의 당첨 통계 계산
- 구매한 로또 대비 수익률 계산

### 6. 로또 당첨 통계 출력

- 구매한 로또 당첨 통계 출력
- 구매한 로또 대비 수익률 출력
